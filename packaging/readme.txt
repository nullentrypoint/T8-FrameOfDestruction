УСТАНОВКА (RU)
1. Установите Microsoft Visual C++ Redistributable x64:
   https://aka.ms/vc14/vc_redist.x64.exe
2. Закройте игру. Распакуйте содержимое архива в папку:
   <папка установки TEKKEN 8>\Polaris\Binaries\Win64\
   Здесь находится Polaris-Win64-Shipping.exe.
   Пример для Steam:
   C:\Program Files (x86)\Steam\steamapps\common\TEKKEN 8\Polaris\Binaries\Win64\
3. Файл dinput8.dll и папка plugins должны оказаться рядом с
   Polaris-Win64-Shipping.exe. Сохраните структуру папок из архива.
4. Запустите игру обычным способом. Плагин загрузится автоматически.
   F1 — открыть меню.

INSTALLATION (EN)
1. Install Microsoft Visual C++ Redistributable x64:
   https://aka.ms/vc14/vc_redist.x64.exe
2. Close the game. Extract the archive contents into:
   <TEKKEN 8 installation folder>\Polaris\Binaries\Win64\
   This is the folder containing Polaris-Win64-Shipping.exe.
   Example for Steam:
   C:\Program Files (x86)\Steam\steamapps\common\TEKKEN 8\Polaris\Binaries\Win64\
3. Place dinput8.dll and the plugins folder next to
   Polaris-Win64-Shipping.exe. Keep the archive's folder structure.
4. Start the game normally. The plugin loads automatically.
   F1 opens the menu.

dinput8.dll: Ultimate ASI Loader by ThirteenAG (MIT license)
https://github.com/ThirteenAG/Ultimate-ASI-Loader
